# NotaDinle audio samples

The instrument recordings are bundled for offline playback. They are OGG previews from Meta Open Sound and are released under CC0 1.0 Universal.

- `piano/`: Meta Piano upright samples, MIDI 36–96, velocity layer 03 (mezzo-forte).
- `guitar/`: Meta Steel Guitar steel-string acoustic samples, MIDI 40–84, velocity layer 02 (medium). The source string is selected to favor a playable low-fret position.
- `SOURCE-SAMPLES.csv`: maps each bundled filename to its original source filename and sample layer/string.

Sources: [Meta Open Sound](https://github.com/facebookincubator/Meta-open-sound), [piano specification](https://github.com/facebookincubator/Meta-open-sound/blob/main/systems/instruments/meta-piano/README.md), [steel guitar specification](https://github.com/facebookincubator/Meta-open-sound/blob/main/systems/instruments/meta-steel-guitar/README.md), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
